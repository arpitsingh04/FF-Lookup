## 📋 BEFORE YOU APPLY - ACTION ITEMS

### 1. **Get a Domain Name** (REQUIRED)
```
Replace in index.html:
- Change "https://yourwebsite.com" to your actual domain
- Update all canonical URLs
- Update Open Graph URLs
```

### 2. **Create Privacy Policy Page** (REQUIRED FOR ADSENSE)
Create `privacy.html` or use a Privacy Policy generator:
- Google "Privacy Policy Generator for AdSense"
- Include sections: Data Collection, Cookies, Third-party ads
- Link from footer

**Required Content:**
```
- What data you collect (UID searches, analytics)
- How you use cookies
- Third-party advertising (Google AdSense)
- User rights and contact info
```

### 3. **Create Terms of Service Page** (RECOMMENDED)
Create `terms.html`:
```
- Service description
- User responsibilities
- Limitation of liability
- Prohibited activities
- Changes to terms
```

### 4. **Create Contact Page** (RECOMMENDED)
Create `contact.html` with:
```
- Email address (create: contact@yourdomain.com)
- Contact form (optional)
- Social media links (optional)
```

### 5. **Setup Your Hosting**
- Upload all files to web hosting
- Ensure HTTPS is enabled (SSL certificate)
- Test on mobile devices

## 💰 Adding Google AdSense Code

Once approved, replace ad placeholders:

### Example - Header Ad:
```html
<!-- BEFORE -->
<div class="ad-space ad-header">
  <div class="ad-placeholder">Advertisement</div>
</div>

<!-- AFTER (with your AdSense code) -->
<div class="ad-space ad-header">
  <ins class="adsbygoogle"
       style="display:block"
       data-ad-client="ca-pub-XXXXXXXXXXXXXXXX"
       data-ad-slot="1234567890"
       data-ad-format="auto"
       data-full-width-responsive="true"></ins>
  <script>
       (adsbygoogle = window.adsbygoogle || []).push({});
  </script>
</div>
```

### Ad Unit Sizes:
- **Header**: 970x90 (Leaderboard) or 728x90 (Banner)
- **Sidebar**: 300x600 (Half Page) or 300x250 (Rectangle)
- **In-Content**: 728x90 (Banner) or Responsive
- **Footer**: 728x90 (Banner)
